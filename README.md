A very simple implementation of a Tower Defense-type game. 
It's poorly coded on purpose to illustrate tight coupling, spaghetti coding and an overall lack of standards or architecture in game development. 
There's a Unity and an Unreal Engine version, to also show an example of how some basic features are implemented in one or the other, or what the equivalent of some engine feature is in the other. 
But again, this is full of bad practices, take this as an example of what NOT to do.
